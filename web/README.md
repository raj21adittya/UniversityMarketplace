This is the Next.js web client for University Marketplace.

## Firebase setup

Create `web/.env.local` from [`web/.env.example`](./.env.example) and fill in your Firebase web app values:

```bash
cp web/.env.example web/.env.local
```

The Firebase config used by the browser is public client configuration, but keeping it in `.env.local` helps avoid committing project-specific values by accident.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

For the hosted email sign-in page under `firebase-hosting/public/signin`, copy `config.example.js` to `config.js` and fill in the same Firebase web values before deploying Hosting. That `config.js` file is ignored by git.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
